# Карта оповещений БПЛА

Неофициальная карта, которая собирает оповещения из открытых Telegram-каналов и показывает, где объявлена опасность по БПЛА или ракетная опасность.

## Что умеет

- Показывает примерные зоны опасности: контур села или посёлка, круг вокруг объекта или улицы, район.
- Убирает зоны после сообщения об отбое или автоматически через некоторое время.
- Отдельно показывает ракетную опасность.
- Кнопка «Где я» показывает, находитесь ли вы в активной зоне и далеко ли до ближайшей. Ваше положение определяется в браузере и никуда не отправляется.
- Лента последних сообщений и поиск по населённому пункту.
- Предупреждает, если какой-то из источников давно не обновлялся.

## Важно

Это неофициальный источник. Данные приблизительные, могут быть неточными или приходить с задержкой. Карта не заменяет официальные оповещения. Следуйте указаниям МЧС и местных властей.

Проект предоставляется «как есть», без каких-либо гарантий.

## Источники данных

Сообщения берутся из открытых Telegram-каналов, права на их содержание принадлежат авторам каналов. Названия мест определяются с помощью OpenStreetMap. Карта © участники OpenStreetMap.

## Для разработчиков

Python (Flask) на сервере, Leaflet на странице. Настройки через переменные окружения: CHANNELS, TTL_MIN, ROCKET_TTL, REGION, VIEWBOX. Неверно определённые места можно задать вручную в файле places.json.
